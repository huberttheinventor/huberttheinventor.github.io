PLAID / THE PLAID LAYER CARD

The plaid layer card

SVD (singular value decomposition) in one picture: any grid of numbers is a stack of plaid layers, strongest first. One layer is one list running down times one list running across: every cell gets its row's number times its column's number, which draws a plaid. Keep the strongest k layers and you have the closest copy any k layers can make.

A  =  σ₁ u₁ v₁ᵀ  +  σ₂ u₂ v₂ᵀ  +  σ₃ u₃ v₃ᵀ  +  …        (σ₁ ≥ σ₂ ≥ σ₃ ≥ … ≥ 0)
symbolin plain words
Athe grid: a grey photo, one brightness number per pixel
uᵢthe list running down (one number per row)
vᵢthe list running across (one number per column)
σᵢthe layer's strength; SVD sorts the layers so it only ever shrinks
σᵢ uᵢ vᵢᵀone plaid layer: cell (row, column) = σᵢ × u's row number × v's column number

What a photo costs, layer by layer

Photo: Albert Einstein, 1921, by Ferdinand Schmutzer (public domain, Wikimedia Commons), cropped to a grey square 900 × 900 pixels = 810,000 numbers. One plaid costs 900 + 900 + 1 = 1,801 numbers.

* error left = size of (photo − copy) ÷ size of photo, both measured as the square root of the sum of squared cells (Frobenius norm).

Size matters. The cost of k layers is k(m + n + 1) numbers while the photo is m × n, so the share shrinks as the photo grows. The same 20 layers cost 7.82% of a 512 × 512 photo (NASA portrait of Eileen Collins, public domain), and 4.45% of the 900 × 900 one. "Under five percent" is true here for a photo about 900 pixels a side, not for every photo.

Why so few layers are enough. Photos are full of smooth, repeating patches, so the strengths fall off fast: layer 20 is 44 times weaker than layer 1 on this crop. TV-style random static has no such patterns: on a 900 × 900 grid of uniform random noise (mean removed), 20 layers still leave an error of 0.958, against 0.204 for the photo with its mean removed (same error measure as the table; our NumPy test, seed 0, 2026-10-23).

Why the strongest k are the best k. Eckart–Young–Mirsky theorem: cutting the SVD after k layers gives the rank-k grid with the smallest error, and that error is the square root of the sum of the squares of the strengths you dropped.

Try it (NumPy)

import numpy as np
from PIL import Image

# 900 x 900 grey crop of the 1921 Einstein portrait (public domain)
A = np.asarray(Image.open("einstein.jpg").convert("L").crop((300, 60, 1200, 960)), dtype=float) / 255
m, n = A.shape
U, s, Vt = np.linalg.svd(A, full_matrices=False)   # s = layer strengths, biggest first

for k in (1, 5, 20, 50):
    Ak = (U[:, :k] * s[:k]) @ Vt[:k]                # stack the k strongest plaids
    kept = k * (m + n + 1) / (m * n)                # two lists + one strength per plaid
    err = np.linalg.norm(A - Ak) / np.linalg.norm(A)
    print(f"{k:>3} layers  {kept:6.2%} of the numbers  error {err:.3f}")
print(f"strength of layer 1 vs layer 20: {s[0] / s[19]:.0f}x")

Output (run 2026-10-23, Python 3.12.10, NumPy 2.4.6, Pillow 12.3.0, on the 1280 × 1681 Commons copy):

The same idea in LoRA

A model's weights sit in grids too. LoRA (Hu et al., 2021) freezes a weight grid W₀ (d × k) and trains a change made of r plaids: ΔW = BA, with B d × r and A r × k, so the layer becomes W₀ + BA. The r in a LoRA config (8 by default in Hugging Face PEFT's LoraConfig) is the number of plaids.

weight gridfull gridLoRA plaids rtrained numbers r × (d + k)share
4,096 × 4,09616,777,216865,5360.39%
12,288 × 12,288 (GPT-3's width d)150,994,944498,3040.065%

What LoRA does and does not do:

  • It trains B and A directly with gradient descent; B starts at zero, so training starts from the original model. It never runs an SVD while training (the paper uses SVD only afterwards, to analyse the learned changes).
  • It bets that the change a model needs is mostly a few strong layers ("low intrinsic rank", the paper's hypothesis). In the paper, "a rank as small as one suffices for adapting both Wq and Wv" on its GPT-3 test sets.
  • It does not shrink the original model; the frozen grid is still all there.

Sources

  • SVD: https://en.wikipedia.org/wiki/Singular_value_decomposition ("Such decompositions always exist for any complex matrix"; the SVD "splits M into a sum of r rank-1 matrices"; singular values are "non-negative" and "Conventionally they are arranged in descending order").
  • Best k layers: https://en.wikipedia.org/wiki/Low-rank_approximation (Eckart–Young–Mirsky: the truncated SVD gives the minimum error over all rank-k matrices).
  • LoRA: E. Hu et al., "LoRA: Low-Rank Adaptation of Large Language Models", arXiv 2106.09685 (https://arxiv.org/abs/2106.09685): "freezes the pre-trained model weights and injects trainable rank decomposition matrices into each layer"; "During training, W0 is frozen and does not receive gradient updates, while A and B contain trainable parameters"; "zero for B, so ΔW = BA is zero at the beginning of training"; "the full rank (i.e., d) is as high as 12,288".
  • PEFT default rank: https://huggingface.co/docs/peft/package_reference/lora (r: int = 8).
  • Photos: https://commons.wikimedia.org/wiki/File:Einstein_1921_by_F_Schmutzer_-_restoration.jpg (public domain); scikit-image data.astronaut (NASA, "released into the public domain").
