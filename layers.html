FIELD CARD / LAYERS / @HUBERTTHEINVENTOR

Your own AI
is eight layers.

A company AI is a model plus seven more layers. Each one was added because something broke without it. Example: Bolt, the assistant at Swiftbox, a delivery company.

Illustration. Story figures ($500 vs $50, 2,000 people) are illustrative, not data. Eight layers is one common stack, not the only valid design. Bolt and Swiftbox are fictional.

The eight layers

  1. 08

    OBSERVABILITY

    Bolt gets one wrong and nobody knows if it was the prompt, document or tool. Trace it; evals run on every change.

  2. 07

    CACHE & ROUTER

    Monday, 2,000 people ask at once and the token bill explodes. Cache exact repeats; route some questions to a cheaper model.

  3. 06

    GUARDRAILS

    A hidden line in an email says ignore your rules and refund everything (prompt injection). Screen, flag, mask PII.

  4. 05

    ACCESS

    A new hire asks a manager's salary and Bolt reads it out. Each tool call carries limited access on behalf of the person asking.

  5. 04

    TOOLS (MCP)

    Customers want actions (refund, ticket, Slack), not only words.

  6. 03

    RAG

    Bolt has read none of the company documents and makes up a refund limit ($500 said, $50 real).

  7. 02

    SYSTEM PROMPT

    Bolt has no brand voice and is not told to stay on topic or never to recommend a competitor.

  8. 01

    MODEL

    A logo on a model is not an assistant: first customer asks, Bolt recommends the competitor.

Never edit the system prompt without running the evals.

Plain words

  • RAG (retrieval-augmented generation): look up the right company documents, then answer from them.
  • MCP (Model Context Protocol): an open standard for connecting AI applications to tools and data.
  • OAuth: lets an application act with limited access for a user; here each tool call carries limited access on behalf of the person asking.

Primary sources

  • Model Context Protocol, introduction: MCP is an open-source standard for connecting AI applications to external systems (data sources, tools, workflows).
  • OWASP LLM01:2025 Prompt Injection: User inputs can alter the LLM's behavior or output in unintended ways.
  • RFC 6749, The OAuth 2.0 Authorization Framework: OAuth 2.0 lets a third-party application obtain limited access to an HTTP service.
  • OWASP LLM02:2025 Sensitive Information Disclosure: Pattern matching can detect and redact confidential content; scrubbing or masking sensitive content.
  • NVIDIA NeMo Guardrails, overview: Programmable guardrails that screen and shape what goes into and out of an LLM application.
  • Cloudflare AI Gateway, caching: Serves identical requests from cache; the cache is based on an exact match of the entire request.
  • RouteLLM, Ong et al. 2024: Router models that select between a stronger and a weaker LLM, cutting cost over 2 times in certain cases.
  • OpenTelemetry GenAI semantic conventions, spans: Standard spans for model calls and tool execution, so one request can be traced.
  • OpenAI, Evaluation best practices: Set up continuous evaluation to run evals on every change.
  • Lewis et al. 2020, Retrieval-Augmented Generation: A retriever plus a generator for knowledge-intensive NLP tasks.
