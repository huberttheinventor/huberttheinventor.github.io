An AI-built app has a particular failure mode: everything works, and all of it looks like 2015. The model writes correct code and default design. These five plugins close that gap — each one carries a piece of design judgement you no longer have to supply yourself.

Five plugins, five different jobs

Feeds the model premium references so it stops designing from the average.

Nº001 · Taste Skill

Borrow someone else's eye

Left alone, a model designs toward the middle of everything it has seen — which is why unaided output looks generic. Taste Skill pulls design taste from premium references and puts it in front of the model before it writes a line of CSS. Reach for it at the start of a build, when the look is still undecided and the default would otherwise win.

Source github.com/Leonxlnx/taste-skill
Nº002 · Web Design Guidelines

An inspector for the interface

Vercel maintains a set of interface guidelines — the small correctness rules of good web UI, from focus states to touch targets. This plugin audits your code against them and flags the weak points before shipping. Run it late, the way you would run a linter: after the build works, before anyone else sees it.

Source github.com/vercel-labs/web-interface-guidelines
Nº003 · Awesome Design

Design systems, already written

A curated collection of DESIGN.md files: complete design systems — colors, typography, spacing — pulled from quality sites and written down in a form a coding agent can follow. Instead of inventing a palette and hoping, you hand the model a system that already hangs together. Reach for it when you want a coherent look without building one from scratch.

Source github.com/VoltAgent/awesome-design-md
Nº004 · Image to Code

From screenshot to component, detail intact

The usual failure of "build me this" with a picture attached is that the model reproduces the layout and loses the finish — the spacing, the shadows, the typographic detail that made the reference worth copying. Image to Code turns a design reference image into usable code without losing that detail. Reach for it when you already know exactly what you want it to look like.

Source github.com/Leonxlnx/taste-skill · skills/image-to-code-skill
Nº005 · Playwright CLI

Let the agent see its own work

A coding agent normally ships blind: it writes the interface and never looks at it. Playwright CLI lets the agent open a real browser, screenshot what it built, and catch broken UI itself — the overlapping button, the invisible text, the layout that collapsed on mobile. Keep it running through the whole build; it is the feedback loop the other four assume.

Source github.com/microsoft/playwright-cli
