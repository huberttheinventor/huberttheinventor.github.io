You commented TICKETS — this is the diagram.

Every piece of Ticketmaster's system arrived only after the one before it broke.

On 15 November 2022, Taylor Swift's Eras Tour presale hit Ticketmaster with 3.5 billion requests in a single day — four times its previous peak. Fourteen million hit the site, bots included; over two million tickets sold that day; and Ticketmaster's own estimate put the trouble at about 15% of interactions across the site. One server was never going to survive that. Here is the system that grew underneath it, one piece at a time — each piece added only after the piece before it broke.

Nº001 · The first fitting

One server falls over the instant every fan arrives

Start with one server holding every ticket. The sale opens, every fan hits it in the same second, and one machine answering that many requests at once falls over immediately. The textbook fix for a surge like that: run the same service on dozens of servers behind a load balancer, so every click lands on whichever server has room to answer it, and any server that stalls gets pulled out of the rotation before it drags the others down.

“A load balancer distributes network traffic across a group of servers, and continuously monitors the health of these servers so it only sends requests to those that are able to respond in a timely manner.”

AWS, “What is Load Balancing?”

Nº002 · The second fitting

A million fans keep asking the exact same question

Now watch what those servers keep getting asked. A million fans refresh the exact same seating map, again and again, and every refresh was hitting the database fresh. Cache it instead: keep the answer sitting ready, and only redraw the map once a seat actually sells, instead of asking the database every time.

“Caching improves application performance by storing frequently accessed data items in a fast, in-memory store … instead of fetching them from a slower back-end store on every request.”

AWS, “What is Caching?”

Nº003 · The third fitting

The queue is the one piece Ticketmaster names itself

The real crush hits next: everyone stops looking and presses buy in the same instant. The fix is to make them wait in line first, and only let in as many as the servers can take — a queue. Ticketmaster runs exactly that: a virtual waiting room, fans call it “the queue,” and it is the one piece of this build that is not a hypothetical — it is the real, named system Ticketmaster's presale ran on. That day it took three and a half billion requests, four times the site's worst day on record, and not every fan in the line was real: bots were hammering it too, pretending to be fans, hoping to grab tickets they could resell before a real fan even got through the door.

“A queue is a temporary repository for messages that are awaiting processing … the receiving application can retrieve the message and process it, at its own pace, without being overwhelmed.”

AWS, Simple Queue Service developer guide

Nº004 · The fourth fitting, and the honest ending

A mirrored queue, and no build invents seats that don't exist

And if the one machine running that queue goes down, everybody in line loses their spot. So you mirror it live, in a second place, ready to step in the moment the first one fails, so the line doesn't just vanish — a replica. Four fixes, each one added only after something broke. That's the difference between a site that bends and a site that goes flat.

It still bent. Ticketmaster's own numbers say about one in seven interactions on the site ran into a problem that day. The fixes kept it bending instead of going flat — but even a flawless site can't invent seats that don't exist. Fourteen million hit the site that day, bots included; there were two million tickets to sell. No build on earth was ever going to close that gap.

“We estimate that of the total 3.5 billion system requests Ticketmaster received … system interruptions were at a scale we have never seen before … roughly 15% of interactions across the site experienced issues.”

Ticketmaster, “Taylor Swift | The Eras Tour Onsale Explained,” 19 Nov 2022
