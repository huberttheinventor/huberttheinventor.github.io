Your video is a web page.

There is no video engine underneath this one. The composition is an HTML file with a CSS block in it, a headless Chrome draws it frame by frame, and the frames are assembled into an MP4. Everything else follows from that: if a browser can paint it, the video can have it.

Nº001

Every word gets a timestamp, and everything hangs off them.

The input is one audio file. Before any picture exists, that audio is transcribed to word-level timestamps — not a word count divided by a duration, but the measured start and end of each spoken word.

That distinction is the whole reason the result stays in sync. A caption that appears because the script said it should appear at 4.2 seconds will drift the moment the narration is re-recorded a shade slower. A caption that appears because the word does cannot drift, because it is reading the same clock as the sound.

Everything downstream inherits those numbers: when a character swaps, when a diagram advances, when a chapter changes colour. Re-record the voice and the film re-times itself.

Nº002

The composition is an HTML file. That is the whole format.

There is no proprietary project file, no binary timeline, no scene graph you can only open in one program. There is a page: elements with start times and durations on them, a stylesheet, and a function that says what the frame looks like at a given moment.

Which means the whole of the web is available as a drawing tool. Typography is typography. A diagram is an SVG. A chart is whatever you would build for a chart. Real footage is a video element sitting inside the layout like any other box.

It also means the file is readable, diffable and reviewable. You can see what changed between two versions of a film the same way you see what changed between two versions of anything else.

Nº003

A browser draws every frame, one at a time.

Rendering is not playback. The page is loaded in a headless Chrome, the clock is set to a specific instant, the frame is captured, the clock moves on. This film is 2,232 of those. ffmpeg then staples them into an MP4 and lays the audio underneath.

The consequence worth understanding is determinism. Because each frame is drawn from a time value rather than from whatever state playback happened to reach, the same composition renders identically every time, and any frame can be produced without producing the ones before it. Nothing can be random, and nothing can depend on the wall clock.

That is also why review works. A studio can seek anywhere in the film and show you the true frame, because seeking and rendering use the same mechanism. What you scrub is what renders.
