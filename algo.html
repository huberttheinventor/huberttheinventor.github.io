The same point, five different answers.

Three thousand points, and all five of these algorithms see exactly the same ones. What changes is how much you tell them before they start: nothing at all, then a number, then a class, then a class cut into boxes, then that same class three hundred times over. Five answers come back about one tracked point, and only one of them is the truth.

The whole mental model, one picture. Everything after it is annotation.

Take it with you: the five-rung ladder, every algorithm and every verdict on one page.

Nº001

Nothing changes except how much you tell it.

Textbooks sort these five by the machinery inside them, which is why the list reads as five unrelated tricks to be memorised separately. Sort them instead by what you hand over before the fitting starts and they become one ladder. K-means is told nothing: no labels, no answer key, only the points. Linear regression is told a number for every point. Logistic regression is told a class instead of a number. A decision tree is told the same class and only changes the shape it is allowed to draw. Boosted trees are told that class three hundred times over, once per tree.

That is the whole taxonomy, and it is why the first two rungs are not really answering the same question as the last three. K-means says which pile a point belongs in when nobody has said what the piles are. Linear regression says how far the point sits from a line it drew. Only rungs three, four and five are being asked which class the point is, so only those three can be right or wrong about it.

Nº002

A quantity and a chance are not the same answer.

Linear regression fits a flat surface through the cloud and reports the gap between the surface and each point. For the tracked point that gap is +0.20, and on its own that figure says nothing at all. Measured against the spread of every other residual it becomes 0.18 standard deviations, which is the only form in which it carries information. Quoting a residual without the spread beside it is how a fit gets called good with no evidence.

Logistic regression takes the same flat surface and bends it into an S. The number that comes out is no longer a quantity, it is a probability, and it can only sit between zero and one. For the tracked point it came out at 0.4997. That is not a wrong answer and it is not a right one. It is the model saying, honestly, that it cannot separate this point from the class boundary, and the point was chosen for exactly that reason: the easy points in this cloud agree across all five rungs and would have shown you nothing.

Nº003

One weak tree, three hundred times.

A single tree stops drawing lines through the cloud and starts cutting it into boxes: bigger than this, go left; later than that, go right. Every leaf is a box, and the box a point falls into is the answer. The tracked point lands in box three of eight, and box three votes A, which is wrong. That failure is also the tree's one real advantage, because you can read the sequence of cuts that produced it. Nothing else on the ladder will tell you why.

Boosting keeps the tree and gives up the explanation. Fit one small tree, measure what it got wrong, then fit the next tree to those mistakes rather than to the original data, and repeat. Each tree on its own is barely better than a guess. Three hundred of them, each correcting the last, drive the accuracy on this cloud from 0.8278 for the bent flat surface to 0.8778, five points, and the boundary they draw together is jagged in a way no single line or single box could be. On the tracked point they return 0.2576, which votes B, and B was the truth. You get the right answer and you lose the ability to say why.
